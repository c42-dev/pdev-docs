<Note>
**子账户之间的分账。** 可选字段 `split` 将部分金额分给您的其他钱包——子账户，或通过保留字 `principal` 指定的主账户。最多 10 项，金额为固定值，以雷亚尔计。

创建收款的一方是**发起方**：收取总额、支付全部手续费，然后才进行分账，因此分账上限是**净额**（收款金额减去手续费），而非总额。分账在结算时执行，而不是在创建时。退款和 MED **只从发起方**扣款——收到分账的一方永远不会被扣款。

完整规则、示例和错误表参见[支付分账](/cn#支付分账)。
</Note>

<Note>
**机构选择。** 如果您的账户已启用此选项，可选字段 `pspCredentialId` 可指定签发本笔收款的机构，忽略已配置的路由。请在控制台的 **设置 → 路由** 中复制该 ID。

指定**不等于优先**：如果该机构不可用或容量不足，收款将失败，而不会改由其他机构签发。响应会回显 `pspCredentialId` 作为回执。

完整规则和错误表参见[机构选择](/cn#机构选择)。
</Note>
